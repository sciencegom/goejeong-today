# 화장실 전자담배 감지기: 설계서

TVOC 센서와 미세먼지 센서로 전자담배 연기를 감지합니다. 감지되면 학교 WiFi로 서버에 알리고, 모니터링 웹페이지가 **붉게 점멸하면서 경보음**을 냅니다.

```
 [화장실]                                   [교무실 PC]
 ┌──────────────────────┐   학교 WiFi     ┌──────────────┐  같은 망  ┌──────────────────┐
 │ ENS160+AHT21 (TVOC)  │  HTTP POST     │ server.js    │  실시간   │ 웹 브라우저         │
 │ PMS5003 (PM2.5)      ├───────────────►│ (Node.js)    ├─────────►│ 🚨 붉은 점멸 + 사이렌 │
 │ ESP32 (판단+전송)     │ /api/report    │              │  (SSE)   │ 본관 2층 화장실 감지! │
 └──────────────────────┘                └──────────────┘          └──────────────────┘
```

```
vape-detector/
├─ firmware/vape_detector/vape_detector.ino   ESP32 아두이노 코드
├─ server/server.js                           모니터링 서버 (설치할 패키지 없음)
├─ server/public/index.html                   점멸·경보음 웹페이지
├─ server/simulate.sh                         센서 없이 화면을 시험하는 스크립트
└─ case/vape_case.scad                        3D 프린팅 케이스 (OpenSCAD)
```

## 2. 배선

```
 ENS160+AHT21 모듈          ESP32 DevKitC              PMS5003 (케이블 핀 번호)
 ┌──────────┐              ┌──────────────┐            ┌──────────────┐
 │ VIN  ────┼──────────────┤ 3V3          │            │ 1 VCC (5V) ──┼──┐
 │ GND  ────┼──────────────┤ GND ─────────┼────────────┤ 2 GND        │  │
 │ SDA  ────┼──────────────┤ GPIO21       │            │ 3 SET (미사용)│  │
 │ SCL  ────┼──────────────┤ GPIO22       │            │ 4 RX  (미사용)│  │
 └──────────┘              │ GPIO16 (RX2)─┼────────────┤ 5 TX         │  │
                           │ VIN (5V) ────┼──────┐     │ 6 RESET(미사용)│  │
                           └──────┬───────┘      │     └──────────────┘  │
                                  │ USB 5V 전원  └───────────────────────┘
```

| 센서 핀 | ESP32 핀 | 비고 |
|---|---|---|
| ENS160 VIN | 3V3 | |
| ENS160 GND | GND | |
| ENS160 SDA | GPIO21 | I2C |
| ENS160 SCL | GPIO22 | I2C |
| PMS5003 VCC (1번) | **VIN (5V)** | PMS5003의 팬은 **5V가 필요**합니다 |
| PMS5003 GND (2번) | GND | |
| PMS5003 TX (5번) | GPIO16 | 신호는 3.3V라서 직접 연결해도 됩니다 |

PMS5003 케이블은 1.25mm 피치라서 일반 점퍼선이 꽂히지 않습니다. **어댑터 보드**를 쓰거나 케이블 끝을 잘라 점퍼선에 납땜하세요.

## 3. 케이스 설계

### 핵심 원칙
1. **2칸 구조.** ESP32는 동작 중에 따뜻해져서 센서 값에 영향을 줍니다. 그래서 칸막이로 **전자부 칸(막힘)**과 **센서 칸(통풍)**을 나눕니다.
2. **통풍구는 아래와 옆으로.** 공기는 잘 들어와야 하고, 물과 먼지는 위에서 떨어지지 않게 합니다.
3. **PMS5003의 공기 흡입구와 배출구는 통풍구 벽 쪽을 향하게** 배치합니다. 막히면 측정이 안 됩니다.
4. **ENS160 모듈은 통풍구 바로 안쪽**에 두고, PMS5003의 배출 바람이 정면으로 닿지 않게 합니다.

### 치수 (바깥 120 × 80 × 40 mm, 벽 두께 2mm)

```
   위에서 본 모습 (뚜껑을 연 상태)
   ┌───────────────────────────┬──────────────────────────────┐
   │ ◎                       ◎ │ ◎   ║ ║ ║ ║ ║ ║ ║ (앞면 통풍) ◎ │
   │                           │                              ═│
 ⊙═╡  ┌────────────┐           │   ┌──────────────┐  ┌─────┐  ═│ ← 끝면 통풍
USB│  │   ESP32    │      배선 ─┼─  │   PMS5003     │  │ENS160│  ═│
   │  └────────────┘   통로     │   │  50×38×21mm   │  └─────┘  ═│
   │        ∘ LED창             │   └──────────────┘ ▒바닥 통풍▒ ═│
   │ ◎                       ◎ │ ◎   ║ ║ ║ ║ ║ ║ ║ (뒷면 통풍) ◎ │
   └───────────────────────────┴──────────────────────────────┘
   ◀────── 전자부 칸 62mm ─────▶◀──────── 센서 칸 56mm ─────────▶
   ◎ = 뚜껑 나사 기둥(M3)    ⊙ = USB 케이블 구멍(Ø7)    양 끝에 벽 고정 날개(Ø4.5 나사 구멍)
```

### 제작 방법

**A. 3D 프린팅 (추천)**
1. [OpenSCAD](https://openscad.org)(무료)로 `case/vape_case.scad`를 엽니다.
2. 맨 위의 `PART = "body";`로 바꾸고 F6(렌더링)을 누른 뒤 STL로 내보냅니다. `"lid"`도 같은 방법으로 내보냅니다.
3. 슬라이서 설정: PLA 또는 PETG(습기에 더 강함), 레이어 0.2mm, 채움 20%. 서포트는 필요 없습니다.
4. 치수는 파일 위쪽의 변수(`L`, `W`, `H`, `SPLIT` 등)만 바꾸면 조정됩니다. 산 부품의 실제 크기를 재서 맞추세요.

**B. 기성품 정션박스 가공**
1. ABS 정션박스(약 120×80×50)를 삽니다.
2. 안에 플라스틱판을 글루건으로 붙여 칸막이를 만듭니다.
3. 센서 칸 쪽 옆면과 바닥에 Ø5mm 구멍을 15~20개 뚫습니다. 드릴이 없으면 인두로 뚫어도 됩니다.
4. 반대편에 USB 케이블 구멍을 뚫습니다. 케이블 그랜드를 쓰면 더 깔끔합니다.

### 설치 위치
- **좋은 곳:** 대변칸 근처 천장, 또는 벽 높은 곳(바닥에서 2m 이상). 손이 쉽게 닿지 않아야 학생들이 가리거나 떼기 어렵습니다.
- **피할 곳:** 환풍기 바로 앞(연기가 바로 빠져나감), 방향제·핸드드라이어 바로 옆(오탐지), 세면대 위(물 튐).
- 전원은 가까운 콘센트에서 받습니다. 선은 몰딩으로 정리하면 뽑히지 않습니다.
- ⚠️ 화장실이므로 **카메라·마이크 없이 공기질 센서만** 있다는 점을 안내문으로 붙여 두고, 학교의 승인을 받고 설치하세요.

## 4. 아두이노 코드 올리기

1. [Arduino IDE](https://www.arduino.cc/en/software)를 설치합니다.
2. **보드 매니저**에서 `esp32` (Espressif Systems)를 설치하고, 보드를 **ESP32 Dev Module**로 선택합니다.
3. **라이브러리 매니저**에서 아래 4개를 설치합니다.
   - `SparkFun Indoor Air Quality Sensor - ENS160`
   - `Adafruit AHTX0`
   - `PMS Library` (Mariusz Kacki)
   - `ArduinoJson` (Benoit Blanchon, v7)
4. `firmware/vape_detector/vape_detector.ino`를 열고 맨 위의 설정을 바꿉니다.
   ```cpp
   const char* WIFI_SSID     = "학교WiFi이름";
   const char* WIFI_PASSWORD = "WiFi비밀번호";
   const char* SERVER_URL    = "http://192.168.0.10:3000/api/report"; // 서버 PC IP
   const char* DEVICE_ID     = "toilet-main-2f-m";    // 기기마다 다르게
   const char* LOCATION      = "본관 2층 남자화장실";  // 웹에 표시될 이름
   ```
5. 업로드한 뒤 **시리얼 모니터(115200)**에서 측정값을 확인합니다. 전원을 켜고 약 3분은 예열 시간이라 감지하지 않습니다.

### WiFi 관련 확인 사항
- 학교 WiFi가 **비밀번호만 입력하면 연결되는 방식**이면 위 설정만으로 됩니다.
- ESP32는 **2.4GHz WiFi만** 됩니다. 5GHz 전용 SSID에는 연결되지 않습니다.
- 학교 WiFi에서는 **기기끼리 서로 통신하지 못하게 막혀 있는 경우**(AP 격리)가 있습니다. 이때는 ESP32가 서버 PC에 접속하지 못합니다. 아래 5번의 `simulate.sh`나 휴대폰 브라우저로 서버 PC 주소에 접속되는지 먼저 확인하세요. 접속이 안 되면 전산 담당 선생님께 문의하거나, 서버를 학교 밖(클라우드)에 두는 방법을 고려하세요.

### 감지 기준 조정 (코드 상단)
| 설정 | 기본값 | 의미 |
|---|---|---|
| `TVOC_RATIO` | 2.5 | 평상시 값의 몇 배 이상이면 '상승'으로 봄 |
| `TVOC_MIN_DELTA` | 300 ppb | 평상시 값보다 최소 이만큼 올라야 함 |
| `PM_MIN_DELTA` | 15 ㎍/㎥ | PM2.5가 이만큼 함께 올라야 함 |
| `CONFIRM_COUNT` | 3 | 몇 초 연속 상승해야 감지로 확정 |
| `COOLDOWN_MS` | 60초 | 감지 후 재알림 금지 시간 |

**현장 테스트 순서:** 먼저 평소 값을 며칠 관찰합니다. 그다음 방향제·락스·손 소독제로 오탐지 여부를 확인하고, 마지막으로 (선생님 입회하에) 무니코틴 전자담배 액상으로 실제 반응을 확인한 뒤 기준값을 정합니다.

## 5. 서버와 웹페이지 실행

교무실 PC에 [Node.js](https://nodejs.org) 18 이상을 설치하세요. 추가로 설치할 패키지는 없습니다.

```bash
cd vape-detector/server
API_KEY=우리학교비밀키 node server.js
```
Windows PowerShell에서는 이렇게 실행합니다: `$env:API_KEY="우리학교비밀키"; node server.js`

- 브라우저에서 `http://localhost:3000`(서버 PC)이나 `http://서버PC의IP:3000`(다른 PC)에 접속합니다.
- 첫 화면에서 **[모니터링 시작]**을 한 번 눌러야 합니다. 브라우저는 사용자가 클릭하기 전에는 소리를 낼 수 없게 막아 두기 때문입니다.
- 오른쪽 위의 **[경보 테스트]**로 점멸과 사이렌을 미리 확인할 수 있습니다.
- 경보가 울리면 **[확인]**을 눌러 소리를 끕니다. 같은 화장실에서 새로 감지되면 다시 울립니다.
- 센서가 35초 넘게 보고하지 않으면 해당 카드가 **'연결 끊김'**으로 바뀝니다. 전원이 뽑혔는지 바로 알 수 있습니다.
- 서버 PC의 IP는 Windows에서는 `ipconfig`로 확인합니다. IP가 바뀌지 않도록 고정 IP를 쓰는 게 좋습니다.

### 센서 없이 화면 시험하기
```bash
./simulate.sh alert test-1 "본관 2층 남자화장실"       # 감지 발생 → 화면 점멸 + 경보음
```
```bash
./simulate.sh heartbeat dev2 "별관 1층 여자화장실"     # 정상 상태 보고
```
```bash
./simulate.sh clear test-1 "본관 2층 남자화장실"       # 감지 해제
```
Windows에서는 Git Bash로 실행하거나, 같은 JSON을 Postman 등으로 `POST /api/report`에 보내면 됩니다.

### 센서가 보내는 데이터 형식
```json
POST /api/report   (헤더: X-API-Key: 우리학교비밀키)
{
  "device_id": "toilet-main-2f-m",
  "location": "본관 2층 남자화장실",
  "event": "alert",            // alert | clear | heartbeat
  "tvoc": 1450, "pm25": 48, "eco2": 900, "aqi": 4,
  "temp": 23.5, "humid": 55, "warming_up": false, "rssi": -61
}
```

## 6. 발전 아이디어 (탐구 확장)
- 감지 기록을 파일이나 DB에 저장하고, 시간대별·장소별 통계 그래프를 그려 보기
- 감지되면 담당 선생님 휴대폰으로 알림 보내기 (텔레그램 봇, 카카오 알림 등)
- 센서 값 그래프를 비교해 전자담배·방향제·샤워 수증기를 구별하는 기준 찾기 (탐구 보고서 주제로 좋습니다)
- 같은 화장실에 센서를 두 개 달아 위치(대변칸 번호) 추정하기
