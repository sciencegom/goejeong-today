# 괴정의 오늘

대전괴정고등학교 안내 화면. 실제 원문을 수집하며 예시 게시글은 사용하지 않습니다.

## 실행

Node.js 24 이상에서 `npm install` 후 `npm start`. http://localhost:3000 접속.
`npm run collect`로 1회 수집, `npm test`로 날짜와 파서 규칙 검사.

## 운영 규칙

- 한국 시간 기준 날짜. 급식은 학교알리미에서 **오늘 날짜의 중식·석식만 요청·저장·제공**합니다. 화면에서도 다시 날짜를 확인합니다.
- 중식/석식 모두 있는 날 10초 간격으로 교대합니다. 한 종류만 있을 때 해당 메뉴를 표시합니다.
- 공지와 대회 게시글은 작성일 기준 오늘 포함 최근 7일만 표시합니다. 8일 전/미래 글은 제외합니다. 이전 공지로 대체하지 않습니다.
- 긴 본문은 화면 높이에 맞춰 나누어 20초마다 순환합니다. 이전/다음/일시정지와 종류 필터를 지원합니다.
- 학사일정은 학교알리미 데이터를 사용하고 월~일 이번 주를 고정 표시합니다.
- 30분마다 원문 재수집, 화면은 1분마다 저장된 자료를 확인합니다. 날짜는 매초 확인해 자정에도 오래된 메뉴/게시글을 표시하지 않습니다.
- 수집원별 실패는 독립적으로 기록하고 마지막 성공 자료를 유지합니다. 마지막 갱신 시각/지연 상태를 표시합니다. 자료는 data/board.json에 원자적으로 저장합니다.
- 학교알리미 페이지가 사용하는 공개 데이터 조회 경로를 서버에서 동일하게 호출합니다. 실제 응답 데이터는 학교알리미가 연결하는 NEIS 서비스에서 내려옵니다. 반환된 조회 URL은 클라이언트나 로그에 노출하지 않습니다.
- HWP/PDF 내부 또는 이미지 글자의 자동 추출은 이번 버전에 포함하지 않습니다. 본문과 첨부 원문 링크를 제공합니다.

## 서체와 화면

Noto Sans KR(구글 폰트), 맑은 고딕 순서로 사용합니다. 폰트 네트워크 연결이 없어도 시스템 서체로 표시됩니다. 부드러운 회백색·딥그린 기반, 데스크톱 전광판과 모바일 배치를 지원합니다.

## 배포

### GitHub Pages

`.github/workflows/pages.yml`은 main 업데이트와 매시 7분/37분(UTC), 수동 실행으로 수집·테스트·정적 빌드·Pages 배포를 수행합니다. 저장소 Settings → Pages → Source를 GitHub Actions로 선택해야 합니다. 주소는 https://sciencegom.github.io/goejeong-today/ 입니다.

예약 실행은 GitHub 부하에 따라 지연될 수 있으며 공개 저장소에서 60일간 활동이 없으면 예약 실행이 비활성화될 수 있습니다. Actions 상태를 주기적으로 확인하세요. 수집 실패 시 Actions 캐시에 남은 정상 데이터를 사용하며, 첫 수집이 전부 실패하면 배포하지 않습니다. 캐시는 영구 백업이 아닙니다. 페이지에는 마지막 성공 시각과 지연 상태를 표시합니다. 메뉴는 화면에서도 오늘 날짜만 표시합니다.

### 직접 서버 운영

한 대의 상시 실행 Node 서버로 화면과 수집기를 함께 운영합니다. HOST=0.0.0.0, PORT 환경변수 지원. 외부 공개 시 HTTPS 리버스 프록시를 연결합니다. 데이터 저장 경로는 DATA_DIR로 지정하고 영구 볼륨을 연결해야 합니다. Dockerfile을 제공하며 /data는 실행 사용자(node, uid 1000)가 쓸 수 있도록 준비해야 합니다. 저장소 자동 배포는 아직 연결하지 않았습니다.

배포 전 `npm test` → 컨테이너 빌드 → 영구 볼륨 연결 → 공개 주소 확인 순서입니다. 동일 볼륨에 여러 수집기 인스턴스를 실행하지 마세요. 소스 구조 변경 시 collector.mjs의 parseList/parseDetail 또는 학교알리미 연동 부분을 수정합니다. 실패 알림의 외부 전송은 미구현입니다.
